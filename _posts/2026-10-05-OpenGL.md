Although I've just began my programming journey with **engine programming** I have began adding physics implementation to a game engine with a friend making all of the same components seen in popular engines like **Rigidbodies**, **Colliders**, **Bounding Volume Hierarchy**, **Raycasting** and **Input Handling** all done with pure C++ utilising a custom maths library to peform all of the calculations.

To make the project, I started late joining a project me and my friend had began where after they built most of the rendering pipeline I began creating basic collission detection with primitive collider shapes like cubes, spheres, capsules and cylinders. As well I implemented raycasting allowing for simple interactions to be done later on when we create a game for the project. As well to ensure extremely optimised collision detection and resolution I utilised the popular algorithm known as bounding volume hierarchy. The project has loads of work needed to get it into a state to build a game in but I will update this page when I add new content.
