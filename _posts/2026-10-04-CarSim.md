This is my realistic car simulator which is a project I started in Unity for one of my assignment that has already outscoped the original criteria. The simulator currently permises an *"arcadey"* simulation type with simple **engine physics, grip, braking and suspension** but now contains **scriptable objects** making it easy to change out different *modules* of the car and swap them out to make them more realistic.

</div>

</div>

<div class="media-row" markdown="1">

<div class="text" markdown="1">

For the *modules*, I create a set of *realistic* variables and *arcade* variables that through an **interface** allows for a single function that makes the tool **easy to apply** to each vehicle with the realistic variables allowing for engines to have **RPM, transmission and gears** with the suspension and grip being more effected by **weather** and **ground types**.

Other than the easy way to change out vehicle types the over arching class is **abstract** allowing all of the physics to be **easily overrided** by special vehicles that work differently from the average car. The system also features a motorbike with the ability to do a wheelie and leaning overriding the original vehicle script to contain many of the same features with altered values.
